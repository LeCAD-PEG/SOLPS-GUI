

==============
Using Runs tab
==============


Af first run of the SOLPS GUI you see an empty and default configuration.

.. image:: runs_1.png


Configure the runs folders
--------------------------

 1. From the menu bar select :guilabel:`&Settings` and :guilabel:`&Runs`.
    A new dialog window for *Runs settings* will open.
 2. Selelect elipsis button :guilabel:`...` and   :guilabel:`Choose` your
    ``runs`` folder that can be found under your SOLPS top (`${SOLPSTOP}`)
    installation.
 3. Optionally you may rename default alias ``local_1`` to this *runs* tree
    to whatever name you like this name seen under the Runs tab.
 4. Optionally you may add up to four such Runs trees and name it. These
    trees may be available under other SOLPSTOP trees or provided by other
    users or project trees if you have at least read access.
 5. Press OK. Trees will be rescaned for status.
